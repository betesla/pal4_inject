# PAL4 Inject v0.2.1

## 今晚修复与更新

### 宽屏与界面布局

- 扩展宽屏 UI 适配：标题主界面、前尘忆梦、旧的回忆、图片列表与查看器、游戏内人物/物品/装备/仙术/锻造/任务/系统菜单、Loading 和战斗页面按各自结构安全铺宽；外围边框贴边或延展，中央列表、人物、文字和弹窗保持原比例，移出原 800×600 区域的按钮仍可正常点击。
- 修复宽屏页面状态判断：只处理当前活动 UI 树，退出菜单或切换场景后不再因残留窗口误加黑边、遮罩或旧布局。
- 修复战斗宽屏布局：行动条与动态头像重新对齐，底部角色状态区重新分布，结算时四个人物属性面板恢复并排展开，不再重叠；Loading 页面背景铺宽但进度组件保持居中。

### 手柄与菜单操作

- 完善启动器手柄操作：左栏上下直接预览对应右栏，A 进入子栏目，B 返回或取消弹窗，Start 启动游戏，Back 退出启动器。
- 固定并简化 Xbox 360 / XInput 映射：“控制”页改为只读展示，不再保留尚未稳定的用户改键入口。
- 修复按下手柄 A 键无法在 3D 场景交互的问题：A 统一映射空格，并同步 Win32 键盘路径与 PAL4 原生 InputManager 的“刚按下/按住/释放”状态；标题确认、读档、对话、拾取和场景机关现在使用同一套行为。
- 修复标题主界面已存在 `PALIV` 对象时被误判为普通 3D 场景的问题，十字键与 B 会根据当前真实 UI 决定导航和返回行为。
- 修复系统 UI 的打开与关闭状态：Back/B 可沿原版 ESC 路径逐层退出，“使用/丢弃”等小弹窗不会残留；从菜单读档或切换场景后会自动清除旧菜单状态，不再出现进入 3D 场景后无法移动的问题。
- 修复系统 UI 分页与换人：LB/RB、LT/RT 自动跳过隐藏、禁用或尚未开放的主/子分页；右侧纵向子页关闭再打开后不再遍历错位；物品、装备和仙术页面无需先移动到顶部箭头即可用左右键直接换人。
- 修复战斗 UI 被普通 3D 场景规则接管的问题：十字键恢复普通方向导航，不再误开 F1～F4 页面；B 返回，X 攻击，Y 防御。
- 完善战斗左摇杆行动轮：五个方向可直选物品、仙术、特技、防御和逃跑，摇杆回中恢复中央攻击；进入具体技能、物品或目标列表后自动改为四向导航，且不会同时驱动场景人物移动。
- 修复手柄模式鼠标指针隐藏和双指针闪烁问题，并保留鼠标重新接管时的正常显示。

### 现代移动与镜头

- 修复现代摇杆移动时小地图不跟随人物位置或朝向更新的问题，补回原版任意方向移动路径遗漏的小地图刷新。
- 修复跑步、快跑时人物动作速度与实际移动速度不一致的问题：摇杆从跑步区间推向快跑区间时，位移倍率由 `1.0×` 线性增加至 `1.5×`，动作倍率由 `1.0×` 同步增加至 `1.4×`。
- 改进大角度转身：突然反推或大幅改变方向时先以行走动作平滑转向；松开摇杆、关闭现代控制或改用键盘时恢复原生移动与动作倍率，避免倍率残留。
- 为稳定发布，v0.2.1 暂不启用战斗右摇杆相机控制，也不安装对应的 `RwCameraBeginUpdate` Hook；普通 3D 场景右摇杆控制不受影响。

### 兼容性与版本识别

- 标题左下角版本文字改为 `PAL V1.2.1`，便于从截图辨识修补版本。
- 修复 CS 文本脚本路径中 `Music.csb` / `worldMap.csb` 的错误命名：CS 模式改读同名 `.cs`；CSB 模式拒绝伪装成二进制脚本的文本文件并安全回退原包资源。

## Xbox 360 / XInput 默认按键

当前版本在启动器“控制”页只读展示这套固定映射，暂不支持用户自行改键。

### 3D 场景（城镇/迷宫）

| 手柄输入 | 游戏功能 |
| --- | --- |
| A | 空格：对话、拾取、场景交互 |
| B | 暂不映射，避免在 3D 场景误触发 ESC |
| Start | F7：打开系统设置页 |
| Back | 无操作 |
| 左摇杆 | 控制人物移动；推动程度线性控制走、跑和快跑 |
| 按下左摇杆（L3） | Tab：切换领队 |
| 右摇杆 | 转动镜头 |
| 按下右摇杆（R3） | 切换镜头远近 |
| X | V：放置发光路标 |
| Y | C：使用当前队长的迷宫技能 |
| 十字键上 / 下 / 左 / 右 | F1 人物状态 / F4 仙术特技 / F2 物品 / F3 装备 |
| LB | 打开小地图 |

### 系统 UI

| 手柄输入 | 游戏功能 |
| --- | --- |
| A | 空格：确认 |
| B | ESC：返回 |
| Start | 无操作 |
| Back | 关闭菜单 |
| 十字键 | 上下左右导航；在物品、装备和仙术页面中，左右键可直接换人 |
| LB / RB | 遍历 F1～F7 主分页，自动跳过禁用或尚未开放的分页 |
| LT / RT | 遍历数字键 1～6 子分页，自动跳过禁用或尚未开放的分页 |

### 战斗 UI

| 手柄输入 | 游戏功能 |
| --- | --- |
| A | 空格：确认；连击提示时可追加连击 |
| B | ESC：返回 |
| X | 直接选择中央“攻击”按钮 |
| Y | 直接选择左下“防御”按钮 |
| 十字键 | 恢复为普通上下左右导航 |
| 左摇杆 | 在行动盘按五个方向选择物品、仙术、特技、防御或逃跑；回中恢复中央攻击；进入具体列表后改为四向导航 |
| 右摇杆 | v0.2.1 暂不启用战斗镜头旋转，以保留原生战斗镜头焦点 |
| 按下右摇杆（R3） | 调整相机远近距离 |

## 使用方式

本次发布包继续包含与注入层配套的 `PAL4.exe`。建议先备份游戏目录中的同名文件，再将压缩包全部内容解压到正版 Steam《仙剑奇侠传四》游戏目录，运行 `PAL4_inject.exe`。
