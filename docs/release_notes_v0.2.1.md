# PAL4 Inject v0.2.1

## 今晚修复与更新

- 扩展宽屏 UI 适配：标题主界面、前尘忆梦、旧的回忆、图片列表与查看器、游戏内人物/物品/装备/仙术/锻造/任务/系统菜单、Loading 和战斗页面按各自结构安全铺宽；外围边框贴边或延展，中央列表、人物、文字和弹窗保持原比例。
- 修复战斗宽屏布局：行动条与动态头像重新对齐，底部角色状态区重新分布，结算时四个人物属性面板恢复并排展开，不再重叠。
- 完善启动器手柄操作：左栏上下直接预览对应右栏，A 进入子栏目，B 返回或取消弹窗，Start 启动游戏，Back 退出启动器。
- 固定并简化 Xbox 360 / XInput 映射：控制页只读展示；A 统一映射空格并同步 Win32 与原生输入状态，修复标题确认、读档、对话和 3D 交互不一致的问题。
- 修复系统 UI 手柄导航：Start/Back/B 的开关与返回路径、LB/RB 主分页、LT/RT 子分页、左右直接换人，以及弹窗残留、读档切场景后仍被判定在菜单内等问题。
- 完善战斗手柄操作：十字键恢复普通方向导航，B 返回，X 攻击，Y 防御；左摇杆行动轮可选五类技能入口，进入具体列表后自动切换为四向导航。
- 改进现代移动：左摇杆推动程度在线性区间内同步控制移动与动作速度，大角度改向使用行走动作平滑转身；修复现代移动时小地图不更新及倍率残留到键盘控制的问题。
- 修复手柄模式鼠标指针隐藏和双指针闪烁问题，并保留鼠标重新接管时的正常显示。
- 标题左下角版本文字改为 `PAL V1.2.1`，便于从截图辨识修补版本。
- 修复 CS 文本脚本路径中 `Music.csb` / `worldMap.csb` 的错误命名：CS 模式改读同名 `.cs`；CSB 模式拒绝伪装成二进制脚本的文本文件并安全回退原包资源。
- 为稳定发布，v0.2.1 暂不启用战斗右摇杆相机控制，也不安装对应的 `RwCameraBeginUpdate` Hook；普通 3D 场景右摇杆控制不受影响。

## 使用方式

本次发布包继续包含与注入层配套的 `PAL4.exe`。建议先备份游戏目录中的同名文件，再将压缩包全部内容解压到正版 Steam《仙剑奇侠传四》游戏目录，运行 `PAL4_inject.exe`。
