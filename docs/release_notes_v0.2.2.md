# PAL4Plus（P4P）v0.2.2

本版只包含相对 v0.2.1 的新增内容：对外名称与启动器文件名更新，以及现代手柄镜头的稳定性修复。

## 本次更新

### 名称与可执行程序

- 项目对外名称由 **PAL4 Inject** 更新为 **PAL4Plus**，简称 **P4P**。
- 启动器由 `PAL4_inject.exe` 更名为 `PAL4Plus.exe`，发布包相应更名为 `PAL4Plus_v0.2.2_win32.zip`。
- 游戏本体名称没有改变，仍为 `PAL4.exe`。`PAL4Plus.exe` 应与 `PAL4.exe` 放在同一目录。
- 旧版的 `PAL4_inject.exe` 不再包含在发布包中。覆盖升级后可删除旧启动器，避免误启动旧版本。
- 内部 `pal4_inject` 数据目录、配置、日志、崩溃报告和调试协议名称保持不变，已有设置可以继续使用。
- 启动器界面、问题反馈文本及 GitHub/Gitee 发布资产统一使用 PAL4Plus（P4P）名称。

### 镜头稳定性

- 修复现代控制下移动数步后镜头突然转回角色背后的问题。
- 修复镜头偶发瞬间大角度闪烁：同时处理原版主循环的尾随角插值和最终自动回正，避免错误角度先被渲染一帧。
- 缩小右摇杆 yaw 保护的生命周期，并在剧情镜头准备、播放及脚本相机模式切换时清除旧跟踪状态，修复剧情镜头被玩家角度带到错误位置的问题。
- 剧情、选敌、技能演出和脚本镜头仍可正常接管焦点；返回可操作场景后再继承新的当前角度。

### 版本辨识

- 标题左下角的运行时版本文字更新为 `PAL V1.2.2`，方便从截图判断修补版本；该处理不改写磁盘上的 `PAL4.exe`。

## 当前边界

- v0.2.2 暂不启用战斗右摇杆相机旋转，以保留原生角色、敌人、选敌和技能演出镜头焦点。
- 手柄按键映射当前只读展示，暂不支持用户自行修改。
- “保持当前自由镜头（忽略脚本模式切换）”仍为实验选项，可能改变部分小场景或剧情的预设镜头。

## 安装

1. 备份现有游戏目录和存档。
2. 将 `PAL4Plus_v0.2.2_win32.zip` 全部解压到正版 Steam《仙剑奇侠传四》游戏目录。
3. 确认 `PAL4Plus.exe` 与 `PAL4.exe` 同级，`runtime.dll` 和 `cli.exe` 位于 `pal4_inject` 子目录。
4. 双击 `PAL4Plus.exe` 配置并启动游戏；不要继续使用旧的 `PAL4_inject.exe`。

本次发布包继续包含与注入层配套的 `PAL4.exe`。
