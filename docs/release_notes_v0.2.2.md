# PAL4Plus（P4P）v0.2.2

本版集中完成启动器品牌更新、Xbox 360 / XInput 手柄操作、现代模拟移动、镜头稳定性修复，以及标题、游戏菜单、Loading 与战斗界面的宽屏适配。

## 名称与安装方式

- 项目对外名称由 **PAL4 Inject** 更新为 **PAL4Plus**，简称 **P4P**。
- 启动器可执行程序由 `PAL4_inject.exe` 更名为 `PAL4Plus.exe`；发布包相应更名为 `PAL4Plus_v0.2.2_win32.zip`。
- 游戏本体名称没有改变，仍为 `PAL4.exe`。`PAL4Plus.exe` 应与 `PAL4.exe` 放在同一目录，并通过 `PAL4Plus.exe` 启动游戏。
- 旧版的 `PAL4_inject.exe` 不再包含在发布包中。覆盖升级后可删除旧启动器，避免误启动旧版本。
- 内部 `pal4_inject` 数据目录、配置文件、日志、崩溃报告及调试协议名称保持不变，已有设置可以继续使用。
- 本次发布包继续包含与注入层配套的 `PAL4.exe`。

## 手柄与现代操作

- 启动器支持标准 XInput 手柄导航：左栏上下切换栏目并预览右侧选项，A 进入子栏目，B 返回，Start 启动游戏，Back 退出启动器。
- 游戏内采用只读固定的 Xbox 360 布局。A 统一映射空格键并同步 PAL4 原生输入状态，修复主菜单、读档、对话和 3D 场景中确认或交互失效的问题。
- Start、Back、B、LB/RB、LT/RT 与十字键会根据 3D 场景、系统菜单和战斗界面采用不同的安全语义；菜单弹窗按原版 Esc 路径逐层关闭，避免残留小弹窗或菜单状态。
- 系统菜单中，左右键可在带角色箭头的人物、物品、装备和仙术页面直接换人；LB/RB 与 LT/RT 会跳过隐藏、禁用或尚未开放的页签。
- 战斗界面的十字键恢复普通上下左右导航。行动盘支持左摇杆五扇区选择物品、仙术、特技、防御和逃跑，回中恢复中央攻击；进入具体列表后自动切换为普通四向导航。B 返回，X 直接攻击，Y 直接防御。
- 左摇杆提供连续 360° 相机相对移动；突然反向或大角度转向时，角色会先使用行走动作平滑转身。
- 走路沿用原版 `0.4×`；跑步到快跑区间中，位移倍率随摇杆幅度从 `1.0×` 连续增加至 `1.5×`，动作倍率同步从 `1.0×` 增加至 `1.4×`。
- 修复现代任意方向移动遗漏小地图位置刷新的问题；松开摇杆、关闭现代控制或切回键盘时，会恢复原生移动与动画倍率。

## 镜头稳定性

- 右摇杆可在普通 3D 场景中旋转镜头，回中后保持当前方位；R3 以当前镜头模式默认距离为基准，在 `0.2× / 0.5× / 1.0× / 1.5×` 四档间循环。
- 修复角色移动数步后镜头突然转回角色背后的问题。现代控制只屏蔽原版主循环的尾随角插值和最终自动回正，不影响脚本显式镜头操作。
- 修复镜头偶发瞬间大角度闪烁：在最终回正之前的原生插值阶段即安全结束尾随状态，避免错误角度先被渲染一帧。
- 缩小右摇杆 yaw 保护的生命周期，并在剧情镜头准备、播放及脚本相机模式切换时清除旧跟踪状态，修复剧情镜头被玩家角度带到错误位置的问题。
- 剧情、选敌、技能演出及其他脚本镜头仍可正常接管焦点；返回可操作场景后再继承新的当前角度。

## 宽屏界面

- 标题主界面、旧的回忆、前尘忆梦、图片列表与查看器等页面采用九宫格式宽屏布局：外围装饰贴边或延展，中央内容保持原尺寸，移出原 4:3 区域的按钮仍可点击。
- 人物、物品、装备、仙术、锻造、任务和系统菜单取消左右黑边；页名、分类、信息和关闭栏贴边，中央人物、列表、说明区和弹窗不拉伸。
- Loading 页面背景覆盖宽屏，进度组件保持居中。
- 战斗 HUD、行动盘、选择窗、目标选择和结算页加入独立宽屏适配；修复行动条与动态头像错位，以及结算四块人物面板重叠的问题。
- 帮助、制作人员、世界地图等使用整张或复合贴图的页面继续保持完整 4:3 显示，避免纹样或文字被强行拉伸。

## 稳定性与辨识

- 修复 `Music` / `worldMap` 文本脚本被原游戏错误命名为 `.csb` 时的加载问题：CS 模式读取同名 `.cs`，CSB 模式拒绝伪装文本并回退 CPK 内的编译版本。
- 标题左下角的原版 `PAL4 v1.1` 在运行时显示为 `PAL V1.2.2`，方便从截图判断修补版本；该处理只修改当前进程内存，不改写磁盘上的 `PAL4.exe`。
- 保留崩溃捕获与用户确认后的问题反馈功能；反馈内容使用 PAL4Plus（P4P）名称，文本日志会先脱敏，minidump 不会自动上传。

## 当前边界

- v0.2.2 暂不启用战斗右摇杆相机旋转，以保留原生角色、敌人、选敌和技能演出镜头焦点。
- 手柄按键映射当前只读展示，暂不支持用户自行修改。
- “保持当前自由镜头（忽略脚本模式切换）”仍为实验选项，可能改变部分小场景或剧情的预设镜头。

## 安装

1. 备份现有游戏目录和存档。
2. 将 `PAL4Plus_v0.2.2_win32.zip` 全部解压到正版 Steam《仙剑奇侠传四》游戏目录。
3. 确认 `PAL4Plus.exe` 与 `PAL4.exe` 同级，`runtime.dll` 和 `cli.exe` 位于 `pal4_inject` 子目录。
4. 双击 `PAL4Plus.exe` 配置并启动游戏；不要继续使用旧的 `PAL4_inject.exe`。
