# PAL4Plus（P4P）使用说明

双击 `PAL4Plus.exe` 会打开中文启动器。所有常用配置都在游戏启动前保存，runtime DLL 不再创建游戏内控制面板。

launcher 左侧按现代游戏设置方式分为 `游戏 / 视频 / 音频 / 控制 / 增强 / 高级`。

启动器启用 ImGui 标准 XInput 导航，并把左右两栏作为明确的主栏目/子栏目：在左栏按上下会切换栏目并预览右侧内容，焦点仍留在左栏；仅按 A 才会进入右侧第一个可操作项，左右方向键不会提前跨栏。右侧按 B 返回当前左栏栏目，弹窗打开时则优先关闭弹窗。Start 可直接启动游戏，Back 可直接退出启动器，底部按钮同时标有对应按键；有弹窗时会暂停这两个全局快捷键以避免误操作。十字键用于右侧选项的上下左右调整，无需在“控制”页另行配置。

## 游戏

- `CS 文本脚本`：适合脚本调试和快速迭代。
- `CSB 原始脚本`：适合普通游玩和回归验证，首次启动默认选中。
- launcher 会把上次启动时选择的 `CS / CSB` 写入 `inject_settings.ini`，下次打开自动恢复。

## 视频

- launcher 会枚举当前连接的全部显示器；无边框模式可选择目标显示器。
- 目标显示器使用 Windows 设备名持久化，显示器断开或设备名失效时会回退到游戏窗口所在显示器，并在运行状态中标记 `fallback=1`。
- `常用分辨率 / 显示器支持`：后者会随所选显示器更新，也可以直接输入宽高。
- `显示模式`提供三种选择：
  - `普通窗口`：使用原游戏的窗口边框，不切换桌面显示模式；窗口可由用户手动拖到其他显示器。
  - `无边框窗口（推荐）`：D3D9 保持窗口呈现，窗口覆盖目标显示器；选择显示器时会同步其当前分辨率，之后仍可手动调整。Alt+Tab 更快，也可减少启动和返回桌面时由显示模式切换造成的黑屏或闪屏。
  - `独占全屏`：保留原游戏独占显示设备和切换显示模式的行为，Alt+Tab 时更容易黑屏或闪屏。当前版本沿用原游戏的默认 D3D9 适配器，不能选择目标显示器，仅作为兼容性回退。
- launcher 在“显示模式”标题旁提供圆形问号，悬停即可查看上述差异说明。
- 宽屏修正不再提供手动复选框：`16:10 / 16:9 / 21:9` 等宽于 `4:3` 的分辨率自动开启，`4:3` 以及更窄比例自动关闭；最终状态与垂直同步一起写入游戏目录的 `config.cfg`。
- 保存 `config.cfg` 前会保留一份 `config.cfg.bak`。

## 音频与控制

- 野外存档界面使用宽屏背景和右下关闭按钮锚定，存档列表保持原比例居中。十字键或左摇杆使用原生方向导航选择存档/分页，A 确认，B/Back 返回；界面打开期间不触发场景快捷键、角色移动或镜头控制。

- 商店商品列表（`TradeWindow`）与买卖选择窗口（`TradeSelectWindow`）识别为菜单：商品列表中十字键上下选择商品、左右调整物品数量；LB/RB 直接切换上一/下一商品栏目（如头部防具、身体防具），支持长按重复，无需先选中顶部箭头；买卖选择窗口或弹窗仍使用普通方向导航。左摇杆保持四向导航，支持长按重复，A 沿用空格确认，B/Back 返回；商店内停用场景快捷键和摇杆移动/镜头控制，关闭后恢复场景输入。

- “音频”页的“对白语音音量”范围为 `0%` 到 `300%`，只作用于 `giTalk` 同步创建的 `PALSOUND/*.mp3` 配音对象。超过 `100%` 会放大原始配音，音源峰值较高时可能削波或失真。
- 游戏内单独按 `[` 降低 5%，按 `]` 提高 5%；按键消息由注入层消费，长按不会连续改写配置。屏幕顶部会显示约 1.6 秒的矢量喇叭、0～3 道音波和精确百分比数字并在末尾淡出；音量为零时显示静音叉号。当前有对白时立即更新，否则从下一句配音开始生效。
- 该倍率不改写原游戏的全局声音值，因此 BGM 和普通音效仍沿用原游戏设置；原游戏全局音效音量继续作为最终配音音量的基础值。
- “控制”页当前支持 0 号 Xbox 360 / XInput 手柄，并只读展示固定按键布局；暂不提供用户改键入口。默认布局以原版键盘按键直映为主。
- 默认 A 键映射空格。运行时会把同一按下/松开时序同时同步给 Win32 键盘路径和 PAL4 原生 InputManager：首次按下保留状态 `2`，持续按住进入状态 `3`，避免跳过 3D 交互使用的“刚按下”状态。B 键只在主菜单和系统 UI 中直接映射 Esc，在城镇、迷宫等 3D 场景中不发送任何按键，避免 Esc 的原版场景副作用。
- 标题主界面及其读档、帮助、回顾、图片、地图和战斗界面通过当前 CEGUI 根窗口识别，不再仅凭 `PALIV` 对象是否存在推断 3D 场景。十字键首次按下时会刷新一次该状态，并在本次按住期间保持选定的导航语义。
- Start、Back 与 LB 按真实 UI 上下文采用固定语义：3D 场景中 Start 映射 F7、Back 无反应、LB 映射 M 打开小地图；进入主菜单或系统 UI 后 Start 无反应，Back 与 B 均映射 Esc，LB/RB 才遍历 F1～F7 主分页。X 映射 V 放置路标，Y 映射 C 使用队长的迷宫技能，L3 映射 Tab 切换领队，R3 循环镜头距离。非战斗 3D 场景中十字键上/下/左/右分别直接映射 F1 人物状态、F4 仙术特技、F2 物品、F3 装备；战斗窗口可见时四个方向固定发送普通方向键，不触发页面快捷键或系统菜单换人；系统 UI 中上下键恢复方向导航，左右键在物品、装备和仙术等带角色箭头的当前页面直接换人，不要求焦点先移动到顶部箭头，无角色箭头的页面和小弹窗仍使用普通左右导航。若存在“使用/丢弃”等小弹窗，Back 会先沿原版 Esc 路径关闭弹窗，再次按下才关闭外层菜单，避免绕过弹窗留下残层。LT/RT 在系统 UI 中遍历数字键子分页；每次切换前读取当前 UI 按钮状态，自动跳过尚未开放、隐藏或禁用的页签。纵向页码由手柄输入连续维护，主页面切换时从默认第一页重新开始，不读取页面关闭后可能残留的按钮焦点。实体按钮与十字键首次按下时会读取当前 UI 快照，避免标题界面或战斗界面因已存在 `PALIV` 对象而被误判为普通 3D 场景。手柄只由原生 `ProcessInputs` 单一路径轮询，避免额外 timer 或渲染回调干扰摇杆状态。
- 战斗行动盘按原始六按钮空间关系处理左摇杆：回中自动收敛到中央攻击，向外推动后按五个 72° 扇区直接选择物品、仙术、特技、防御和逃跑；使用独立的启动/释放阈值与 10° 方向滞回，防止摇杆轻微抖动反复跳项。行动盘可见时 B 发送 Esc，X 直接触发中央攻击，Y 直接触发左下防御；这些战斗特例不改变普通 3D 场景中 B 无映射、X=V、Y=C 的规则。打开具体物品、仙术、特技或目标列表后，左摇杆自动切换为带长按重复的普通四向导航。战斗期间左摇杆不会再驱动场景角色移动；v0.2.2 暂不启用战斗右摇杆相机控制，以保留原生战斗镜头焦点。
- 如果从系统 UI 中读档或加载场景，WindowManager 可能保留局部 `visible` 仍为真的旧按钮对象。输入循环会检查 `frameToolbar/btnClose` 是否仍通过父节点链挂在当前 `GUISheet`，连续两个输入帧脱离当前 UI 树就自动清除旧菜单状态；无需再按 Start，进入新场景即可使用方向键和摇杆移动。
- L3（按下左摇杆）固定调用原版 `Tab` 切换领队，不再用于切换移动速度或自动前进。
- 默认启用“现代摇杆控制”：左摇杆使用连续 360° 的相机相对方向，角色朝向会跟随摇杆方向；突然反推等大角度改向会先以行走动作平滑转身，接近目标方向后恢复正常速度。走路沿用原版 `0.4×`，进入跑步区间后，移动速度会随推动幅度从跑步 `1.0×` 连续增加到快跑 `1.5×`，动作速度也同步从 `1.0×` 增加到原版快跑的 `1.4×`。现代移动会补回原生任意方向函数遗漏的小地图位置更新。关闭后左摇杆退回兼容旧实现的 W/A/S/D 数字输入。
- 右摇杆按“度/秒”灵敏度旋转自由视角，并支持横向（X 轴）和纵向（Y 轴）独立反转，同时勾选两项即可全反转；按下 R3 会以当前镜头模式的原版默认距离为基准，在 `0.2× / 0.5× / 1.0× / 1.5×` 四档间循环。摇杆死区使用 XInput 对 Xbox 360 布局定义的标准死区。
- 任一有效手柄按钮、扳机或摇杆输入会隐藏鼠标箭头；真正移动鼠标后，UI 中只显示 CEGUI 游戏光标，3D 场景只显示原生 Win32 光标，避免 OIRAMLOOK 灰色指针与系统指针同时出现。游戏自身的窗口中心回中消息不会误触发恢复。
- 现代控制会保持当前右摇杆镜头方位，并只屏蔽原版主循环在无鼠标横向输入时执行的尾随插值和最终回正；剧情、脚本和相机模式切换仍可接管镜头，返回可操作场景后再继承新的当前角度。
- “保持当前自由镜头（忽略脚本模式切换）”为实验选项：`SetCameraMode` 脚本执行后会恢复切换前的镜头模式，用于阻止小场景切回经典 45 度固定视角。它也可能改变剧情演出的预设镜头，出现异常时应关闭。

## 增强

该页只保留面向普通玩家的稳定选项，不再逐条展示底层 Hook。

- launcher 根据所选分辨率自动设置宽屏修正，并统一启停：
  - 4:3 UI 居中与菜单黑边
  - 动态字体重同步
  - 小地图与 HUD 布局修正
  - 战斗浮字、提示窗与结算图片修正
  - Bink 过场视频比例修正
- 标题主界面 `MainWindow/Root` 会把九宫格边框和左右按钮扩展到物理屏幕两侧，中央 Logo 保持居中，并取消该页原有的左右黑边。“旧的回忆”读档页、“前尘忆梦”影片列表、图片列表/查看器及旧版在线信息页同样扩展四周边框，但中央存档列表、缩略图、图片和说明区保持原尺寸居中；帮助、制作人员、世界地图等使用整张或复合贴图且不适合安全拆分的界面继续保留 4:3 黑边。
- 游戏内人物、物品、装备、仙术、锻造、任务和系统七页会取消原有左右黑边：公共顶边与底边连接条延展到宽屏两侧，左侧标题和右侧分类/信息/关闭栏贴近物理屏幕边缘；人物、存档、列表、说明文字与弹窗保持原始尺寸和布局，不做横向拉伸。WindowManager 中未挂到当前活动树的旧对象不会参与布局。
- Loading 页会把背景横向铺满，但通过父子坐标补偿让进度条、亮条和转动图标继续位于屏幕中央。战斗页会把敌人数、底部状态栏和角色卡分配到宽屏空间，并分别处理行动盘、物品/仙术/特技选择窗、目标选择窗和结算页；行动条与动态小头像作为整体保留原位，结算四块人物属性面板继续由原版动画并排展开，场景画面与中央内容不会随 UI 一起拉伸。历史 `ui_ab` 是项目早期手改版，只用于效果比对，不代表官方资源。
- 游戏标题流程左下角的原版标识 `PAL4 v1.1` 会由注入层显示为 `PAL V1.2.4`，用于截图辨识修补版本；该处理只修改当前进程内存，并会在原字节不匹配时拒绝应用。
- “前尘忆梦”的 `MoviePlayWindow` 使用独立宽屏边框修正：`zuo/you` 竖框保持原宽度并贴到物理屏幕边缘，`shang/xia` 横框扩展到两侧边缘，`anniukuang` 按钮框跟随右框移动。运行时会临时解除这些边框子窗口的父级裁剪并提高横框最大宽度，退出该布局后恢复原状态；Bink 视频仍使用所选过场比例模式，不随 UI 边框一起横向拉伸。
- 所有已识别的 UI 根界面都经过声明式宽屏配置选择“铺宽、HUD 锚定或保持居中”策略。运行时只处理当前活动 `GUISheet` 中的配置窗口，隐藏或 WindowManager 残留页面不会被其他界面的规则误改。
- MSAA 支持 `关闭 / 2x / 4x / 8x`；选择非关闭等级时会同时启用底层 MSAA Hook。
- launcher 保存的是期望配置。显卡或游戏可能拒绝某个 MSAA 等级，实际结果应查看 runtime 日志或 CLI 状态。
- “过场视频显示”提供两种保持原比例的模式：
  - `完整显示（保持全画面）`：整个视频都保留，宽屏下允许左右留黑。
  - `宽屏铺满（上下裁剪）`：优先铺满屏幕宽度，保持比例并裁掉超出屏幕的上下画面。
- “过场视频显示”标题旁的圆形问号会展示两种模式的完整差异；两种模式都不会拉伸视频。
- 相机俯仰保护仍保留独立开关，它不属于宽屏预设。
- “松散文件补丁”是独立开关。启用时，CPK 资源与 CS 文本脚本都优先读取 `gamepatch\gamedata\...`；CPK 未命中仍可回退原 CPK，但 CS 脚本缺失或读取失败会直接失败，不会回退游戏目录 `editData`。关闭开关才恢复原版直读路径；发行版没有 `editData` 时，CS 模式因此不可用。两种状态都会记录到独立加载日志。

## 高级调试

这里可以逐项设置 HookMode 和详细日志：

- 宽屏预设管理的 Hook 仍保留在表格中，便于对当次启动做临时回归排查；下次打开 launcher 或改变分辨率时会再次按画面比例同步。

- `仅观察`：统计调用，不替换游戏行为。
- `镜像比对`：用于实验性对照。
- `替换（可回退）`：优先使用注入实现，必要时回退原逻辑。
- `强制替换`：不回退，主要用于开发验证。
- `日志`：只为选中的功能写入详细运行记录，普通使用建议保持关闭。
- 松散文件补丁固定使用 `gamepatch\loose_file_load.log`，所以高级表格显示“独立文件”，不受通用详细日志复选框控制。
- CS 文本源码统一使用 `.cs` 扩展名；原游戏误写的 `Music.csb` / `worldMap.csb` 会自动改查 `Music.cs` / `worldMap.cs`。CPK 入口遇到伪装成 `.csb` 的文本文件会拒绝覆盖并回退包内编译版本。

## 反馈 Bug

- launcher 会检查 `pal4_inject` 子目录中的最新崩溃文本，并在侧栏显示“发现崩溃”。
- 可填写 Issue 标题、问题现象和复现步骤，并选择是否附带：
  - 最新崩溃文本
  - runtime log 末尾
- 选中的诊断文本会先在本地脱敏并显示完整预览。游戏目录、Windows 用户目录和常见令牌/密码字段不会按原值带入正文。
- 只要选择了任一诊断项，就必须额外勾选授权确认，按钮才会启用。
- 点击“复制内容并打开 Gitee”后，launcher 会打开预填的 Gitee 新建 Issue 页面，并将完整正文复制到剪贴板。请在网页中再次检查并手动提交；URL 过长导致预填截断时可直接粘贴剪贴板内容。
- 第一版不会读取或上传 `.dmp`，也不会在后台静默创建 Issue。

## 配置与运行状态

- 新配置文件：`pal4_inject\inject_settings.ini`
- 脚本选择使用 `script_mode=cs|csb` 持久化；旧配置缺省该项时使用 `csb`。
- Bink 显示模式使用 `bink_scaling_mode=fit|fill_width_crop` 持久化；旧配置缺省该项时使用“完整显示”。
- 对白语音音量使用 `gi_talk_volume=0.000..3.000` 持久化；旧配置缺省该项时使用 `1.000`（100%）。
- 镜头反转分别使用 `gamepad_invert_camera_x` 和 `gamepad_invert_camera_y` 持久化；旧配置缺少 X 轴设置时默认不反转，保留原有 Y 轴设置。
- 支持读取 RTX Remix 实验启动器写入的版本 12 配置，保留手柄、窗口、音量和 Hook 设置；实验专用键在普通构建中忽略。
- 手柄设置使用 `gamepad_*` 持久化；按键布局为只读固定值，版本 11 起不再写入 `gamepad.binding.<button>`。旧配置中的自定义绑定可被兼容读取，但会统一迁移到当前固定布局。旧配置缺省时启用现代控制、走跑阈值为 `0.620`、右摇杆灵敏度为 `120.0` 度/秒，而自由镜头保持默认关闭。
- 无边框窗口使用 `borderless_window=0|1` 持久化；旧配置缺省该项时沿用 `config.cfg` 的普通窗口或独占全屏设置。
- 无边框目标显示器使用 `borderless_monitor=\\.\DISPLAYn` 持久化；旧配置或无效设备名自动选择主显示器。
- 旧版 `pal4_inject\inject_panel_settings.ini` 会被兼容读取，并在下次从 launcher 启动时迁移到新文件名。
- runtime 会在 Hook 安装前加载配置。
- 游戏运行期间如需改变 HookMode，底层 IPC 协议仍保留 `set_hook_mode`；普通 CLI 主要用于状态和事件日志观察。
- 实际安装状态、调用次数和错误通过以下渠道查看：
  - `pal4_inject\pal4_inject_runtime.log`
  - `gamepatch\loose_file_load.log`（CPK / CS 松散文件覆盖、CS 必需文件缺失与 CPK 回退，UTF-8 JSON Lines）
  - `cli.exe --pid <pid> state`
  - `cli.exe --pid <pid> event-log`
- `state` 中的 `borderless_window_enabled / borderless_monitor` 表示期望配置，`borderless_window_applied / borderless_window_summary` 表示本次实际应用结果。
- `state` 中的 `gi_talk_volume` 表示期望倍率；首次实际播放配音后，`gi_talk_volume_applied / gi_talk_volume_summary` 会记录是否成功写入对应配音对象。
- `state` 会导出 `gamepad_connected / gamepad_context / gamepad_modern_controls / gamepad_run_threshold / gamepad_fast_run_threshold / gamepad_camera_sensitivity`，便于确认手柄连接和运行配置。
- 音量提示复用宽屏 CEGUI renderer 的最终绘制阶段，因此会覆盖在普通 CEGUI 界面之上；如关闭宽屏 renderer 修正，快捷键和音量倍率仍工作，但当前版本不绘制该提示。

## 故障排查

- 自动更新：每次打开启动器会在后台检查正式版本。有可安装新版时，版本号旁出现向上箭头；点击可查看说明，再点“更新并重启”。下载时可取消；若游戏仍运行，请保存并退出，启动器会自动继续。没有网络或没有新版时不弹窗，也不影响启动游戏。
- 手动安装与自动更新使用同一个完整 ZIP，包含并替换 `PAL4.exe`、增强启动器和运行库等托管文件，不覆盖存档、MOD 或配置文件。开始安装前会保存启动器当前设置。新版不能正常打开时会回滚；意外中断后再次打开启动器会尝试恢复。若提示恢复失败，请保留 `.pal4plus-update` 中的备份。详见 [自动更新与恢复](auto_update.md)。

- launcher 无法初始化界面：确认系统存在 DirectX 9 runtime 和可用显卡驱动。
- 中文退回默认字体：确认 `C:\Windows\Fonts\msyh.ttc` 存在。
- 配置无法保存：确认游戏目录和 `pal4_inject` 子目录可写。
- 某项配置无效果：先检查 runtime 日志是否明确记录 Hook 安装成功，再判断游戏行为。
