# PAL4Plus（P4P）下一版本发布说明（草案）

v0.2.2 的正式说明见 [release_notes_v0.2.2.md](release_notes_v0.2.2.md)。后续更新内容从这里继续整理。

## 手柄镜头控制

- 启动器“控制”页增加右摇杆横向（X 轴）反转，与纵向（Y 轴）反转独立保存；同时开启即可双轴全反转。旧配置保留原有 Y 轴选项，X 轴默认不反转。

## 启动器自动更新

- 打开时后台检查更新，发现可安装新版后在版本号旁显示更新图标；点击查看说明并下载、校验、安装，完成后重新打开启动器。
- 移除旧的“检查更新”按钮和跳转下载页流程。离线检查静默失败；下载失败可重试，相同更新包可跨 Gitee/GitHub 回退。
- 游戏运行时等待玩家自行退出；安装保留存档和设置，支持备份、启动失败回滚和中断恢复。
- 发布脚本增加独立更新 ZIP 与 `update.json`，不把游戏本体或用户配置纳入自动更新。
