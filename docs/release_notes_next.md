# PAL4 Inject 下一版本发布说明（草案）

## 主要更新

- 简化 Xbox 360 / XInput 手柄确认键：默认 A 键现在只表达空格键动作，不再按主菜单、系统 UI、对话或 3D 场景选择不同语义；运行时同时同步 Win32 键盘输入和 PAL4 原生 InputManager，并保留“刚按下”到“持续按住”的状态过渡，修复 UI 有效但 3D 交互无效的问题。
- 修复现代摇杆移动时小地图标记不更新的问题。角色移动后会补回原版任意方向移动分支缺少的小地图位置刷新。
- 改进左摇杆的模拟移动速度。走路继续沿用原版 `0.4×`；从“跑步触发幅度”到“快跑触发幅度”之间，移动倍率会随摇杆推动程度从 `1.0×` 连续增加至 `1.5×`，不再突然切换两档速度。
- 同步改进角色动作速度。跑步到快跑之间，动作播放倍率会随移动倍率从 `1.0×` 连续增加至原版快跑使用的 `1.4×`，减少脚步动作与实际位移不同步的问题。
- 新增大角度平滑转身。左摇杆突然反向或大幅改变方向时，角色会暂时使用行走动作并限制转向速度，完成转身后再恢复当前摇杆力度对应的跑速，避免角色瞬间掉头。
- 修复连续模拟倍率可能残留到键盘控制的问题。松开摇杆、关闭现代控制或改用键盘时，会恢复当前原生移动模式的速度与动作倍率。
- 修复 `Music` / `worldMap` 文本脚本被原游戏错误命名为 `.csb` 的加载问题。CS 模式现在自动读取同名 `.cs` 源码；CSB 模式会拒绝长度头无效的松散 `.csb` 并安全回退 CPK 内的编译版本，避免场景加载末尾崩溃。

## 当前转身参数

- 最大转向速度：`360°/秒`。
- 目标方向与当前朝向相差超过 `20°` 时，进入行走转身阶段。
- 上述参数当前为首版默认值，可根据实机手感继续调整。

## 验证情况

- Win32 `RelWithDebInfo` 构建通过。
- 自动化测试全部通过，覆盖走、跑、快跑端点、跑到快跑的中间线性倍率，以及正向突然反向时的限速转身。
- 手柄映射测试覆盖默认 A 键绑定确认动作、确认动作只在对应映射按钮实际按下时生效，以及原生键状态按 `刚按下 2 -> 按住 3 -> 释放 1` 顺序推进而不跳过交互边沿。
- 松散文件测试覆盖 `.csb` 文本请求到 `.cs` 候选的映射、合法编译 CSB 的长度头接受，以及伪装成 `.csb` 的文本文件拒绝与回退判定。
- 修复版已成功注入 Steam 游戏进程，输入、玩家控制、小地图及现代控制相关 Hook 均已安装。

## 建议检查项目

1. 分别在开始界面、读档列表、对话和 3D 场景中按 A，确认其行为与键盘空格键一致。
2. 使用左摇杆移动，确认小地图上的角色位置或方向会持续更新。
3. 缓慢把摇杆从跑步阈值推到快跑阈值，确认位移和动作播放速度连续变化。
4. 前推摇杆后突然反推，确认角色使用行走动作平滑转身，没有瞬间旋转 180°。
5. 松开手柄并改用键盘，确认键盘的走、跑、快跑速度仍与原版一致。
