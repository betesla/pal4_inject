# PAL4Plus（P4P）下一版本发布说明（草案）

v0.2.2 的正式说明见 [release_notes_v0.2.2.md](release_notes_v0.2.2.md)。后续更新内容从这里继续整理。

## 手柄控制

- 启动器“控制”页增加右摇杆横向（X 轴）反转，与纵向（Y 轴）反转独立保存；同时开启即可双轴全反转。旧配置保留原有 Y 轴选项，X 轴默认不反转。

- 商店商品列表（`TradeWindow`）与买卖选择窗口（`TradeSelectWindow`）识别为菜单：商品列表中十字键上下选择商品、左右调整物品数量；LB/RB 直接切换上一/下一商品栏目（如头部防具、身体防具），支持长按重复，无需先选中顶部箭头；买卖选择窗口或弹窗仍使用普通方向导航。左摇杆保持四向导航，支持长按重复，A 沿用空格确认，B/Back 返回；商店内停用场景快捷键和摇杆移动/镜头控制，关闭后恢复场景输入。

## 配置兼容

- 修复从 RTX Remix 实验构建切回普通构建时，版本 12 配置被整份拒绝，导致手柄、无边框窗口等设置未应用的问题。

## 野外存档界面

- 补齐 `SaveWindow` 的宽屏背景和关闭按钮锚定，存档列表保持居中原比例。
- 将野外存档纳入独立菜单识别，支持十字键/左摇杆方向导航、A 确认、B/Back 返回，避免被当作场景输入。
