# PAL4 Inject 下一版本发布说明（草案）

## 主要更新

- 注入启动器新增标准 XInput 手柄导航，并把左栏视为主栏目、右栏视为其子栏目：左栏上下切换栏目并保持焦点以预览右侧内容，仅按 A 才进入右侧第一个选项，B 从右栏返回当前左栏栏目或优先关闭弹窗；Start 直接启动游戏、Back 直接退出且底部按钮标有快捷键；嵌套设置区不再要求二次进入焦点层级。
- 手柄布局改为只读固定展示，暂不支持用户改键。Start、Back 与 LB 采用上下文固定语义：3D 场景中 Start=F7、Back/B=无、LB=M；主菜单或系统 UI 中 Start=无、Back/B=Esc、LB/RB=主分页。X=V、Y=C；3D 场景十字键上/下/左/右分别打开 F1/F4/F2/F3 页面。进入 UI 后，上下保持方向导航，左右可在物品、装备和仙术等带角色箭头的页面直接换人，不再要求先把焦点移动到顶部箭头；无换人控件或存在小弹窗时回退普通左右导航。关闭时沿原版 Esc 逐层退出，避免“使用/丢弃”小弹窗残留。LB/RB 与 LT/RT 会读取当前菜单按钮状态，自动跳过尚未开放、隐藏或禁用的主/子页签。
- 修复标题主界面已创建 `PALIV` 对象时被误判成 3D 场景的问题。十字键首次按下会核对当前 UI 快照，并在整个按住周期内保持方向导航模式，不再错误发送 F1/F4/F2/F3；B 键也使用同一主界面识别结果决定是否发送 Esc。
- 修复战斗 UI 被普通 3D 场景规则接管的问题。战斗主界面、行动盘、三类选择窗、目标选择和结算窗口任一可见时，十字键固定恢复为上下左右导航，不再触发 F1/F4/F2/F3 快捷页；系统菜单中的左右换人逻辑保持不变。
- 战斗加入专用双摇杆操作：行动盘用左摇杆五扇区直选物品、仙术、特技、防御和逃跑，具体技能/物品/目标列表中自动切回普通四向导航；左摇杆不再误驱动场景移动。修复右摇杆参数变化但画面静止的问题：输入阶段只累计目标角度，在战斗控制器更新完成后、RenderWare 开始绘制前才提交到可见相机；提交前直接继承原生相机 `+0x74/+0x78/+0x7C` 的权威焦点，不再从上一帧 RenderWare 矩阵反推。右摇杆回中后不再保留修改角度，而是立即撤销渲染前覆盖，使选敌头顶指针、敌人特写、技能镜头与脚本切镜可在下一次原生更新中接管相机。扇区带启动、释放和角度滞回，降低摇杆回中与边界抖动造成的误选。
- 修复战斗按钮上下文：战斗 UI 中 B 现在按 Esc 返回，行动盘可见时 X 直接攻击、Y 直接防御；左摇杆从外环回中会先把焦点恢复到中央攻击，不再因提前清空扇区状态而停留在上一技能类别。普通 3D 场景继续保持 B 无映射、X=V、Y=C。
- 标题流程左下角的版本文字由原版 `PAL4 v1.1` 显示为 `PAL V1.2.1`，方便通过截图辨识修补版本。实现为带原字节校验的进程内数据补丁，不改动磁盘上的游戏本体。
- 修复右侧纵向子分页关闭后再次打开时 LT/RT 遍历错位的问题。CEGUI 会保留已关闭页面按钮的旧焦点，但实际内容已回到默认页；现在纵向页码由手柄状态连续维护，并在主页面变化时归零，不再用残留焦点覆盖当前页。
- 游戏内人物、物品、装备、仙术、锻造、任务和系统菜单完成宽屏适配并取消左右黑边。公共顶部/底部连接条铺宽，左侧页名与藤叶装饰、右侧分类、游戏信息和关闭栏分别贴边；中央人物、存档、物品列表、说明区及弹窗保持原尺寸，避免文字、头像和点击区域变形。普通 3D HUD 或 WindowManager 中未挂到活动树的旧对象不会触发布局。
- Loading 与战斗页面加入独立宽屏 profile。Loading 背景铺到两侧，进度条及动画仍保持居中；战斗主 HUD 将敌人数、底部状态条和角色卡合理分布到宽屏空间，并单独适配行动盘、物品/仙术/特技选择窗、目标选择和结算页。行动条及其动态小头像保持成组原位，结算四块人物属性面板保留原版展开动画，修复条框与头像错位及四块面板重叠。早期手改 `ui_ab` 仅作历史效果参考，不再视为官方布局依据。
- 标题主界面完成九宫格式宽屏适配：左右大型装饰及对应按钮分别贴近屏幕边缘，中央 Logo 保持居中，只扩展顶部和底部连接条；主界面背景铺满宽屏并取消左右黑边，移到 4:3 父窗口外的按钮仍可正常接收鼠标点击。帮助、制作人员等保持居中的复合标题子界面继续保留黑边。
- 宽屏 UI 修正升级为根界面作用域的声明式配置系统。每个已识别 UI 明确选择铺宽、HUD 锚定或保持居中，并以窗口首次出现时捕获的原始位置和尺寸计算目标布局；切换配置可精确恢复，不再依赖一组容易失配的硬编码坐标，也不会修改不在当前活动 UI 树中的残留窗口。
- “前尘忆梦”影片列表新增九宫格宽屏布局：四周装饰贴边、上下连接条扩展，缩略图网格和说明区域保持原尺寸居中，右下关闭按钮移到屏幕边缘后仍可正常点击。制作人员等顶部为复合贴图的页面明确保留 4:3 黑边，避免强行拉伸造成纹样和按钮变形。
- “旧的回忆”读档页新增九宫格宽屏布局：只移动和延展外围八块边框，中央 `SaveWindow0` 存档列表、分页和滚动控件保持原尺寸居中；关闭按钮随右下父框移动，避免对子窗口重复补偿。
- 继续扫描标题 UI 资源并新增图片列表 `picturePreviewWindow`、图片查看器 `PictureViewWindow` 和旧版在线信息页 `olInfo` 的安全铺宽 profile。三者只延展标准外围边框并移动关闭按钮；图片、文字和查看控件不拉伸。帮助、制作人员、仙剑探密、仙剑问答及世界地图因使用整张或顶部复合贴图，明确保留 4:3。
- 修复“前尘忆梦”播放页的宽屏边框被中间 800×600 父窗口裁断的问题。左右竖框保持原宽度并分别贴到屏幕两侧，上下横框在解除父级裁剪和最大尺寸限制后覆盖新增宽度，右下按钮框随右边框完整移动；视频画面继续按过场显示模式保持比例，不随边框拉伸。
- 简化 Xbox 360 / XInput 手柄确认键：默认 A 键现在只表达空格键动作，不再按主菜单、系统 UI、对话或 3D 场景选择不同语义；运行时同时同步 Win32 键盘输入和 PAL4 原生 InputManager，并保留“刚按下”到“持续按住”的状态过渡，修复 UI 有效但 3D 交互无效的问题。
- 修复现代摇杆移动时小地图标记不更新的问题。角色移动后会补回原版任意方向移动分支缺少的小地图位置刷新。
- 改进左摇杆的模拟移动速度。走路继续沿用原版 `0.4×`；从“跑步触发幅度”到“快跑触发幅度”之间，移动倍率会随摇杆推动程度从 `1.0×` 连续增加至 `1.5×`，不再突然切换两档速度。
- 同步改进角色动作速度。跑步到快跑之间，动作播放倍率会随移动倍率从 `1.0×` 连续增加至原版快跑使用的 `1.4×`，减少脚步动作与实际位移不同步的问题。
- 新增大角度平滑转身。左摇杆突然反向或大幅改变方向时，角色会暂时使用行走动作并限制转向速度，完成转身后再恢复当前摇杆力度对应的跑速，避免角色瞬间掉头。
- 修复连续模拟倍率可能残留到键盘控制的问题。松开摇杆、关闭现代控制或改用键盘时，会恢复当前原生移动模式的速度与动作倍率。
- 修复 `Music` / `worldMap` 文本脚本被原游戏错误命名为 `.csb` 的加载问题。CS 模式现在自动读取同名 `.cs` 源码；CSB 模式会拒绝长度头无效的松散 `.csb` 并安全回退 CPK 内的编译版本，避免场景加载末尾崩溃。

## 当前转身参数

- 最大转向速度：`360°/秒`。
- 目标方向与当前朝向相差超过 `20°` 时，进入行走转身阶段。
- 上述参数当前为首版默认值，可根据实机手感继续调整。

## 验证情况

- Win32 `RelWithDebInfo` 构建通过。
- Win32 `Release` 自动化测试全部通过，覆盖走、跑、快跑端点、跑到快跑的中间线性倍率、正向突然反向时的限速转身，以及 `RwCameraBeginUpdate` 分派桩的完整 8 字节跳板复制。
- 手柄映射测试覆盖固定 A/B/X/Y/Back/Start 布局、Start/Back/LB 的 3D 与 UI 上下文分流、战斗 B/X/Y 特例与行动轮回中收敛路径、普通 3D 快捷页/战斗纯方向/系统菜单换人三种十字键模式、禁用页签跳过及循环边界，以及原生空格键状态按 `刚按下 2 -> 按住 3 -> 释放 1` 顺序推进而不跳过交互边沿。
- 松散文件测试覆盖 `.csb` 文本请求到 `.cs` 候选的映射、合法编译 CSB 的长度头接受，以及伪装成 `.csb` 的文本文件拒绝与回退判定。
- 修复版已成功注入 Steam 游戏进程，输入、玩家控制、小地图及现代控制相关 Hook 均已安装；新增 `RwCameraBeginUpdate @ 0x759E20` 显示 `installed=1`。战斗中推动右摇杆时，逻辑 yaw/pitch 从 `171.11° / 24.56°` 连续变化到 `2.57° / 32.79°`，RenderWare 最终帧矩阵的 right/at 向量与 eye 位置同步变化，证明活动输入期间的渲染前提交已越过战斗控制器覆盖；当前策略在右摇杆回中时主动停止提交，不把该角度锁定到后续战斗镜头。

## 建议检查项目

1. 分别在开始界面、读档列表、对话和 3D 场景中按 A，确认其行为与键盘空格键一致。
2. 在 3D 场景按 B，确认没有触发 Esc；打开系统 UI 后按 B，确认可正常返回。
3. 验证 3D 场景中 Start/LB/X/Y 分别对应 F7/M/V/C、Back/B 无反应；进入系统 UI 后验证 Start 无反应、Back/B 可逐层关闭、LB/RB 可遍历主分页，再验证 3D 十字键上/下/左/右分别打开 F1/F4/F2/F3。
4. 在物品、装备和仙术页面把焦点留在任意内容项，按十字键左右应直接切换角色；打开“使用/丢弃”等小弹窗后，左右键只操作弹窗，不切换底层角色。
5. 在装备或仙术页用 LT/RT 切到非默认纵向子页，切换到其他主页面再返回；再次按 LT/RT 应从当前实际显示的默认页继续，且连续按键每次只移动一页。
6. 依次打开人物、物品、装备、仙术、锻造、任务和系统页，确认左右黑边消失，左侧页名、右侧分类/信息/关闭栏靠边，顶部和底部连接条连续铺宽；中央人物、列表、存档和弹窗不拉伸，鼠标与手柄点击区域正确。再完全退出菜单，确认普通 3D 场景不残留菜单布局或遮罩。
7. 打开“前尘忆梦”播放页，确认左右竖框贴边、上下横框连续覆盖全宽、右下按钮框贴近右侧，同时视频内容没有被横向拉伸。
8. 使用左摇杆移动，确认小地图上的角色位置或方向会持续更新。
9. 缓慢把摇杆从跑步阈值推到快跑阈值，确认位移和动作播放速度连续变化。
10. 前推摇杆后突然反推，确认角色使用行走动作平滑转身，没有瞬间旋转 180°。
11. 进入标题主界面，确认背景与边框铺满宽屏、Logo 居中、左右按钮靠边；分别用鼠标点击左右按钮，确认移到原 800×600 区域外的按钮仍能进入对应页面。
12. 打开“旧的回忆”读档页，确认外围边框铺满、中央存档列表未拉伸，并用鼠标点击右下角关闭按钮；再打开“前尘忆梦”和已解锁的图片列表/查看页做同样检查，最后打开制作人员或世界地图，确认整张/复合贴图页面仍保持完整的 4:3 黑边。
13. 松开手柄并改用键盘，确认键盘的走、跑、快跑速度仍与原版一致。
14. 从读档触发一次 Loading，确认背景覆盖左右两侧且进度组件仍居中；进入战斗后检查敌人数、行动条与小头像对齐、底部三名角色状态卡和行动盘，再依次打开物品、仙术、特技与目标选择窗口；结算时确认四块人物属性面板从动画起点展开后并排显示，没有重叠、裁切或横向拉伸。
15. 在普通 3D 场景按十字键确认仍打开 F1/F4/F2/F3，且 B 无动作、X/Y 仍对应 V/C；进入战斗后分别在行动盘和物品、仙术、特技、目标选择窗口按四个方向，确认只进行上下左右导航，不打开系统页面。行动盘上检查 B=Esc、X=攻击、Y=防御，再将左摇杆依次推向五个扇区并回中，确认外推直接选中相应类别、回中恢复中央攻击且不移动角色；打开具体列表后确认左摇杆改为四向导航，同时右摇杆可以连续旋转战斗镜头。
16. 进入标题主界面，确认左下角显示精确文本 `PAL V1.2.1`，截图中字符完整且没有截断或残留原版 `PAL4 v1.1`。
