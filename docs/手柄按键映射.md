# 手柄按键映射

由于游戏原本即支持全键盘操作，因此除了特殊手柄摇杆操作外，尽量直接映射，避免复杂逻辑。
## 游戏原按键映射

《仙剑奇侠传四》键盘操作完整速查表
| 按键 | 功能说明 |
| --- | --- |
| W / ↑ | 向前移动 |
| S / ↓ | 后退 |
| A / ← | 左转 |
| D / → | 右转 |
| R | 平时切换“走/跑/快跑”；战斗中重复上一次招式 |
| F | 自动前进 |

| 左Ctrl + 移动鼠标 | 任意调整视角方位 |
| C | 使用当前队长的迷宫特殊技能（捕兽夹/搜宝箱/迷烟/搜矿石，效果因队长而异） |
| V | 放置路标（发光标记），防止迷路 |

## 当前默认方案

当前版本只在控制页展示以下固定布局，暂不提供用户自行修改按键映射的入口。

### 3D场景（城镇/迷宫）
A键 映射空格键
B键 在3D场景中暂不映射
start 按键 进入系统设置页 即 键盘F7
back 按键 无反应
左摇杆 控制人物移动
左摇杆按下 切换领队

右摇杆控制镜头
右摇杆按下 切换镜头远近

X映射V键 放置发光标记（迷宫中）
Y映射C键 使用迷宫技能

十字键上键 打开人物状态界面 即F1
十字键下键 映射到F4仙术、特效界面
十字键左键 映射F2物品界面
十字键右键 映射F3装备界面

LB打开小地图

### 系统UI内保留操作
A键 映射空格
B键 ESC
start键 无反应
back键 关闭菜单
左摇杆

十字键恢复为上下左右导航
当在物品装备仙术页面中时，左右键可以直接换人

LB / RB 遍历F1~F7主分页，但需要跳过禁用或者暂未开启的主分页，且总遍历次数相应调整，避免空位置也算进来

LT / RT 遍历数字键1~6子分页，也要跳过及调整次数（见上一条）


### 野外存档界面

| 按键 | 功能说明 |
| --- | --- |
| 十字键 / 左摇杆 | 使用原生方向导航选择存档或分页；支持长按重复 |
| A | 确认，映射空格键 |
| B / Back | 返回，映射 Esc |

界面打开期间不触发场景快捷键，摇杆不控制角色和镜头；关闭后恢复场景操作。

### 商店界面

商店商品列表使用以下操作，切换栏目无需先把焦点移到顶部箭头。

| 按键 | 功能说明 |
| --- | --- |
| LB | 切换到上一商品栏目，如头部防具、身体防具等；支持长按重复 |
| RB | 切换到下一商品栏目；支持长按重复 |
| 十字键上 / 下 | 选择商品 |
| 十字键左 / 右 | 调整当前商品数量 |
| 左摇杆 | 四向导航，支持长按重复 |
| A | 确认，映射空格键 |
| B / Back | 返回或关闭当前窗口，映射 Esc |

买卖选择窗口和弹窗使用原生方向导航。商店内摇杆不控制场景人物和镜头，退出商店后恢复场景操作。

### 战斗UI

A映射空格
B映射ESC
X是攻击快捷键(对应中间按钮) 
Y是防守快捷键(对应左下按钮)
上下左右恢复为上下左右导航
左摇杆可以选择技能类别,类似gta5中那种技能轮,回中后则自动选择中间的按钮
右摇杆转动镜头在 v0.2.1 发布版中暂不启用，以保留原生战斗镜头焦点；按下右摇杆仍可调整相机远近距离
LT+X/A/B分别对应 左边换人、中间换人、右边换人按钮
