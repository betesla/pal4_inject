# PAL4Plus（P4P）v0.2.3

本版仅列出相对 v0.2.2 的更新。

## 手柄镜头

- 新增右摇杆横向（X 轴）反转，可与纵向（Y 轴）反转独立设置；同时开启即可双轴全反转。
- 反转选项自动保存，旧配置保留原有 Y 轴设置，X 轴默认不反转。

## 商店操作

- 修复商店界面未被识别为菜单，导致手柄无法正常操作的问题。
- 十字键上下选择商品、左右调整数量；LB/RB 直接切换头部防具、身体防具等商品栏目，支持长按连续切换。
- 左摇杆支持方向导航，A 确认，B/Back 返回；进入商店后暂停场景移动和镜头控制，退出后恢复。

## 野外存档

- 补齐野外存档界面的宽屏适配：背景铺满画面，关闭按钮靠右下边缘，存档列表和分页保持原比例居中。
- 修复野外存档界面无法使用手柄的问题，支持十字键/左摇杆导航、A 确认、B/Back 返回。

## 配置与版本显示

- 修复从 RTX Remix 实验构建切回普通构建时，配置版本不兼容导致手柄、无边框窗口及其他设置未应用的问题。
- 游戏标题界面的版本文字更新为 `PAL V1.2.3`，启动器版本更新为 `v0.2.3`。
