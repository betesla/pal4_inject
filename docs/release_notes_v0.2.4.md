# PAL4Plus（P4P）v0.2.4

本版仅列出相对 v0.2.3 的更新。

## 启动器自动更新

- 启动器打开后在后台检查 Gitee / GitHub 正式版本；发现可安装新版时，版本号旁显示更新箭头。离线或检查失败时不弹窗，不影响正常启动游戏。
- 点击更新箭头可查看版本说明，再选择“更新并重启”。启动器会下载并校验更新包，安装完成后重新打开启动器。
- 下载期间可取消，失败后可重试；两个发布源提供相同更新包时，下载失败会尝试另一来源。
- 游戏仍在运行时，等待玩家保存进度并自行退出，再继续安装。
- 更新保留存档、MOD 和用户配置；安装前保存当前启动器设置，支持备份、启动失败回滚和更新中断后的恢复。

## 更新入口与发布包

- 移除旧的“检查更新”按钮及外部下载页跳转流程，解决点击下载却打开作者主页的问题。
- 发布统一为一个包含 `PAL4.exe` 的完整 ZIP，手动安装与自动更新共用；配套更新清单校验压缩包及各程序文件的大小与 SHA256，保留用户配置。
- 启动器版本更新为 `v0.2.4`，游戏标题界面的版本文字同步为 `PAL V1.2.4`。

**从 v0.2.3 或更早版本升级时，请先手动下载完整安装包并覆盖安装一次。自动更新功能从 v0.2.4 开始提供，用于后续版本升级。**

已安装最初双包版 v0.2.4 的用户，也请重新下载当前完整包覆盖一次，以支持后续统一包格式；同版本不会再次弹出更新提示。
