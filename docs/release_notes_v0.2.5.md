# PAL4Plus（P4P）v0.2.5

本版用于验证从统一包版 v0.2.4 自动升级到新版本的完整流程。

- 启动器版本提升为 `v0.2.5`，游戏标题界面同步显示 `PAL V1.2.5`。
- 继续提供一个包含 `PAL4.exe` 的完整安装包，手动安装与自动更新共用，附带配套的 `update.json` 校验清单。
- 本次未新增游戏功能，功能与统一包版 v0.2.4 一致。

测试时重新打开统一包版 v0.2.4 启动器，等待版本号旁出现更新箭头，点击查看说明并选择“更新并重启”。完成后确认启动器显示 `v0.2.5`、原有设置保留，再启动游戏确认标题版本为 `PAL V1.2.5`。

若仍使用最初双包版 v0.2.4，其启动器不支持统一包格式，请先手动安装修订后的统一包版 v0.2.4，再测试本次自动升级。
