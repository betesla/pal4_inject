# PAL4 Inject v0.2.0

## 主要更新

- 新增中文图形启动器，集中设置显示器、分辨率、窗口模式、垂直同步、MSAA 和脚本模式；宽屏修正会按画面比例自动启用。
- 改进宽屏 UI、高清文字、HUD、小地图和 Bink 过场显示，并支持无边框窗口。
- 新增 Xbox 360 / XInput 手柄支持：可编辑按键映射，左摇杆模拟方向与走跑力度，右摇杆控制镜头，支持菜单翻页、换人和镜头距离切换。
- 新增 `giTalk` 对白语音独立音量，范围 `0%–300%`，支持游戏内单键调节和简洁音量提示。
- 新增 `gamepatch` 松散文件覆盖，可优先加载资源与 CS 文本脚本。
- 新增需用户确认的 Bug 反馈入口，可附带脱敏后的崩溃记录或运行日志，并打开 Gitee Issue 页面供用户最终检查提交。
- 扩充崩溃捕获、运行日志、CLI 调试和多类只读 Hook 观测，提升 Steam 版本注入与问题排查的稳定性。

## 使用方式

本次发布包暂时包含与注入层配套的 `PAL4.exe`。建议先备份游戏目录中的同名文件，再将压缩包全部内容解压到正版 Steam《仙剑奇侠传四》游戏目录并运行 `PAL4_inject.exe`。
