# PAL4 Inject v0.2.0

## 主要更新

- 使用新的 ImGui 中文启动器统一管理分辨率、全屏、宽屏、垂直同步、MSAA、脚本模式和高级 Hook 配置。
- 新增 `gamepatch` 松散文件覆盖，可优先加载 CPK 资源和 CS 文本脚本，并通过独立 JSON Lines 日志记录加载结果。
- 扩展 CLI 的 UI 自动化、状态等待和运行时诊断能力。
- 增加 Bink 过场视频的完整显示与宽屏铺满模式。
- 继续收口宽屏、战斗 UI、HUD、小地图和输入坐标换算。
- 增加媒体、战斗、进程失败及移动碰撞等运行时观测能力，便于定位闪退和场景问题。

## 架构调整

- 移除旧游戏内注入控制面板，配置统一保存到 `pal4_inject\inject_settings.ini`。
- 重构 Hook inventory、x86 trampoline、输入队列和后台自动化支持。
- 扩充单元测试、集成测试及发布脚本验证。

## 测试提示

- 本次测试构建包含移动碰撞只读观测 Hook；该 Hook 记录碰撞调用，不修改游戏碰撞结果。
- 测试闪退时请保留 `pal4_inject_runtime.log`、崩溃文本报告和对应 minidump。
